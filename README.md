# ESP32 Sandbox

This repository is used as a sandbox for testing ESP32 features, such as adding a hard-wired Ethernet port to a Cheap Yellow Display (CYD).

## :wrench: Hardware Reference

Before wiring new components or starting a new sandbox, please consult the [Hardware Pinouts](docs/pinouts.md) document to avoid pin collisions and verify standard wiring methods.
