# :test_tube: ESP32 Sandbox :zap:

[![Test](https://img.shields.io/github/actions/workflow/status/nicholaswilde/esp32-sandbox/test.yaml?branch=main&style=for-the-badge)](https://github.com/nicholaswilde/esp32-sandbox/actions/workflows/test.yaml)
[![task](https://img.shields.io/badge/Task-Enabled-brightgreen?style=for-the-badge&logo=task&logoColor=white)](https://taskfile.dev/#/)

This repository is used as a sandbox for testing ESP32 features, such as adding a hard-wired Ethernet port to a Cheap Yellow Display (CYD).

## :wrench: Hardware Reference

Before wiring new components or starting a new sandbox, please consult the [Hardware Pinouts](docs/pinouts.md) document to avoid pin collisions and verify standard wiring methods.
